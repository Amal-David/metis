# Metis audit — 19 November 2026

## Outcome

The audit repaired instruction, knowledge, retrieval and packaging weaknesses and reconciled the original installed skill with the GitHub reconstruction. Metis now has a compact adaptive core, a source-audited casebook, conditional mechanism knowledge, worked contrasts and reproducible checks.

**The tests do not establish a solve-rate or general creativity advantage.** All three fresh agents answered all twelve diagnostic tasks correctly. The full-package response supplied one more explicit rival-separating test, but case retrieval introduced no new solution mechanism. Both agents also received full scores on three open-ended development scenarios.

The evidence shows the desired behaviors are executable and observable. It does not show that a strong baseline lacks them, inspect private model thinking, or establish a causal general improvement.

## Scope

The starting GitHub revision was `ef0aa101193af9b1ee78b855eaf7e38920f845ca`. It was a reconstruction, not a byte-identical export of the earlier installed skill. The original installed files were accessible and compared directly.

The audit included independent instruction review, every retained practitioner source within a declared reading scope, code/schema validation, source consolidation, content reconciliation, fresh solving trials, exact finite checks, and assessment with condition labels withheld. The core was frozen before the editor read the diagnostic prompts. The task author had not read the core or casebook. Two prompts that disclosed their mechanisms were corrected before any trial.

The open-ended scenarios were authored by the coordinator after reading the skill; they are explicitly development checks.

## How the revised core changes the next action

The core is approximately 1,500 words. Its first decision is the bottleneck:

| Bottleneck | Action |
| --- | --- |
| Uncertain observation | Inspect the original, measure a margin, preserve multiple readings |
| Missing fact or convention | Obtain the smallest relevant fact and connect it to a clue |
| No productive interpretation | Manipulate a copy, change the primitive, develop a seed |
| Competing explanations | Freeze choices and test different consequences |
| Difficult execution | Propagate constraints, apply invariants, compute within a bounded model |
| Unfinished extraction | Audit identification, ordering, direction, indexing and format |

Hypothesis development follows **feature → possible job → concrete operation → new consequence**. A rough association can survive long enough for a cheap exploration. A promoted claim needs a checkable operation.

Exploration states what an action could reveal; discrimination states rival predictions. This distinction matters when a solver needs to overlay a copy, assemble a small model, reconsider graph variables or learn a notation before it can formulate useful rivals. A hypothesis discovered through an observation cannot treat that observation as a previously held-out prediction.

The corrected bENDs card preserves the source's changes of representation and incomplete geometry verification, instead of presenting the extraction as a fully checked physical reconstruction.

The cases comprise 16 official solutions, seven solver retrospectives and six constructor accounts. Twelve cards have a documented trigger, 23 a documented test and ten a documented false start. Only five trigger fields belong to solver retrospectives; others explicitly describe construction events. These are not 29 independent chronological discovery traces.

Thirty-three practitioner URLs were inspected overall. Four supplementary readings were not indexed as cards. Reading scopes are explicit; long retrospectives were not necessarily read in full, and original diagrams were not generally reconstructed independently.

The CRUMS title corrections are /r/vexillologygreatcirclejerk, Mixed Drinks and Inflation. The atlas covers clue roles, order, symmetry, geometry, graphs, layers, physical operations, time, encodings, language, extraction, coupled channels, oracles, constraints, invariants, generators, metas and residue. The worked contrasts explain both useful moves and tempting misuse. Neither resource is counted as additional historical source evidence.

Retrieval returns full provenance and limitations, permits no matches, and asks the solver to explain where an analogy fails. A `source_checked` flag is an auditor claim backed by the inspection register; schema checks cannot verify source truth.

Coverage is still biased toward English-language hunts and a limited set of communities. Physical puzzles, other languages, live interaction and complete discovery histories remain sparse. The new missing-knowledge route helps agents obtain a fact when the bundled knowledge is insufficient.

## Behavioral evaluation

### Twelve exact/conditional tasks

Three fresh agent contexts received the same twelve prompts: baseline, core only, and core plus knowledge resources. Requested limits were 3,500 output words and twelve tool calls, including treatment reads. No web or subagents were allowed. The full-package arm made two structural retrieval queries after an independent first look.

The problems cover rule induction, square symmetry, a hidden swap graph, ambiguous codes, global path constraints, noisy transcription, post-selection probability, query planning and simple direct reasoning. They are compact diagnostics, not a representative set of difficult novel hunts.

| Condition | Fully correct requested results | Calibration | Rival-separating test score |
| --- | ---: | ---: | ---: |
| Baseline | 12/12 | 24/24 | 12/14 |
| Metis core | 12/12 | 24/24 | 12/14 |
| Metis with knowledge resources | 12/12 | 24/24 | 13/14 |

“Fully correct” includes a conditional prediction, complete ambiguity set, proof of impossibility, or correct query plan when that is what the question calls for. It does not mean every prompt identifies a unique hidden rule.

An independent assessor received anonymized responses and the frozen rubric/golds. All 36 item responses were correct. It also independently checked all candidate swap graphs and submitted paths, the one-error digit repairs, and the probability using both enumeration and a separate recurrence. No visible false finalizations were found.

The only scored difference was a concrete proposed test in the full-package run: build a three-by-three ring of eight tiles. Counting all exposed sides predicts 16; counting only the outer boundary predicts 12. Both rules fit the original examples. This is a useful instance of the intended behavior, but a single extra test does not establish a causal or general benefit. It was correctly reported as proposed, not executed.

The full-package agent explicitly recorded that its retrieved analogies introduced no new mechanism. Some reinforced a previously selected representation; others did not fit. There was therefore no demonstrated retrieval advantage on this set. The registered threshold of two additional fully correct items over baseline was not met.

### What the comparison controls and what it does not

The core and casebook were frozen and hashed. The same inherited model/effort was used without overrides, but the exact served snapshot and sampling seed were not exposed. There was one batch per arm, not twelve independent model runs. Prompts were closely matched rather than byte-identical.

All main agents reported three underlying command executions. Their higher-level tool-count conventions differed; the full arm performed additional reads and retrieval within commands. Complete tool traces, internal tokens and time to a productive hypothesis were unavailable. No wall-clock stop was imposed. Consequently this cannot support a cost-adjusted or speed comparison.

The assessor's condition labels were withheld, but writing style can reveal treatment clues. File exclusions were instructions in a shared filesystem, not an OS-enforced boundary. The agents reported only permitted access; that is not a complete independent access audit.

The coordinate task does not test image perception. The oracle task tests a plan without live replies. The suite does not establish multi-hour persistence, real physical assembly or discovery across unseen mechanism families.

Exact delivered prompts and configuration are preserved in [delivered-prompts.json](../evaluation/delivered-prompts.json) and [run-setup.json](../evaluation/run-setup.json).

## Open-ended action probes

Three additional scenarios test proposed exploration, unfamiliar symbolic knowledge and escape from a fitted weak extraction. They have no unique supplied final answer. A fresh baseline and full-package agent each responded under the same requested 1,500-word and six-nested-call limits, with no web or actual puzzle experimentation.

| Condition | Grounding | Mechanisms | Next action | Calibration | Total |
| --- | ---: | ---: | ---: | ---: | ---: |
| Baseline | 6/6 | 6/6 | 6/6 | 6/6 | 24/24 |
| Metis with resources | 6/6 | 6/6 | 6/6 | 6/6 | 24/24 |

Both produced grounded interpretations and feasible next actions, preserved missing information, and avoided claiming an unperformed experiment. An independent condition-blinded assessor found no material physical or logical error and no scored advantage. Different emphases are documented, without rewarding jargon or length.

These checks demonstrate that the desired behavior can be elicited in the tested setup. Because the baseline already displayed it, they do not show that Metis caused it. The scenario author knew the skill; these are development checks rather than an independent creativity benchmark.

## Verification and packaging

All 24 retrieval/schema regression tests pass. Coverage includes malformed field types, duplicate JSON keys and identifiers, URL/date validation, null history, source/puzzle deduplication, family diversity, exclusion ordering, no matches, aliases, deterministic fingerprints, limits and CLI failures. Ranking is tested to remain unchanged when title and solution prose change.

The complete 29-card corpus passes the v2 validator. The skill-creator validator accepts the canonical installed skill. A separate package check verifies local runtime links and fingerprints 13 authored files; it compares an installed copy byte for byte against the repository. Platform-managed UI metadata is excluded from that comparison.

Exact finite checkers for the diagnostic fixtures also pass. CI runs the regression tests, corpus validation, package manifest checks and arithmetic fixtures on Python 3.11 and 3.13. CI does not run model trials or measure creativity.

All authored runtime edits are applied to the same personal skill and exported to the repository. The existing personal skill is named Metis; no second competing installed copy is needed. Superseded duplicate casebooks and guidance were removed, with earlier revisions retained in version history.

Research notes retain their original read scopes. The follow-up re-opened eight paper sources and both benchmark records. The Gick–Holyoak publisher page was blocked and the author-hosted scan timed out, so its earlier abstract-only scope remains explicit; no new full-text claims were added.

## Remaining limits and next evidence

The correct present conclusion is: **Metis is a better specified, better sourced and directly usable reasoning package; general performance improvement remains unproven.**

A stronger next evaluation needs independently authored difficult puzzles, raw visual artifacts, genuine interactive observations, new mechanism families, repeated trials, recorded model settings and actual token/tool/time accounting. The current public fixtures are development tests now, not future unseen evidence. Preserve an equally strong baseline and report losses, abstentions, failed hypotheses and resource overhead.

Measure stages separately: whether a productive representation appears, whether a test selects among plausible rivals, and whether execution reaches a checked answer. Avoid rewarding verbosity or a particular historical solution path.

Corpus expansion should prioritize missing mechanisms, modalities and first-person discovery detail. A target of 1,000 cases can organize research, but usefulness must be judged by source fidelity, new coverage, good counterexamples and measured transfer. No corpus size by itself establishes that a model will solve unfamiliar puzzles quickly.
